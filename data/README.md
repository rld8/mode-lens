# Data policy

`raw/` is immutable and ignored by Git except for its placeholder. `interim/` and
`processed/` contain reproducible derivatives and are also ignored. User videos are
processed locally and are never copied into a run unless the user does so explicitly.

The two files under `samples/` are generated by `scripts/build_demo_assets.py`; they
contain no third-party footage or personal data. Their exact numeric ground truth,
generator name and seed live in `expected_modes.json`. Rebuild them with:

```bash
uv run python scripts/build_demo_assets.py
sha256sum data/samples/*
```

The MP4 bitstream can differ across OpenCV/FFmpeg builds. Scientific acceptance is
therefore based on decoded motion and ground-truth tolerances, not a frozen video hash.
